# 好友实时画板 Idea

## 一句话概念

为两位好友提供无需文字的共享画板：在线时同步看到彼此每一笔，离线时可以把完成作品送入好友画作信箱，并尽力发送手机通知。

## 已确认需求

- 仅限现有好友关系使用，不开放陌生人匹配。
- 两个人进入同一共享画板后，实时同步笔画。
- 双方使用不同画笔颜色，并显示对方当前落笔位置。
- 基础工具包括画笔、橡皮擦、撤销、清空和表情贴纸。
- 画完后可生成图片并发送给好友。
- 好友离线时，作品进入画作信箱，之后上线仍可查看，不会丢失。
- 尝试向离线好友发送系统通知；点击通知直接打开对应画作。

## 设备策略

- iPhone：安装到主屏幕后申请 Web Push 权限。
- Android：有可用推送服务时使用 Web Push；部分中国大陆机型可能延迟或无法到达。
- 所有设备均以画作信箱作为可靠兜底，推送失败不影响作品送达。

## 推荐技术方案

- 实时笔画：Supabase Realtime 私有好友房间，只传输压缩后的笔画点，不逐帧传整张图片。
- 成品存储：画布导出图片后上传 Supabase Storage。
- 画作信箱：Supabase 数据表保存发送人、接收人、图片路径、已读状态和时间。
- 权限：沿用好友关系和封禁规则，RLS 只允许发送者与接收者访问。
- 离线通知：PWA Service Worker + Web Push；Cloudflare Worker 提供订阅与发送接口。
- 隐私：实时草稿默认不入库，只有用户主动发送的成品才持久化。
